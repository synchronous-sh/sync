# synchronous

Native iOS app: save what you find online, then actually use it.

This tree is the Swift app. Capture still happens through the iOS share sheet (TikTok, Instagram, YouTube, X, Reddit, articles). The home, Learn, News, and Videos tabs follow Rahul’s dark UI and learning paths. Library, AI summaries, and imports come from Aadi.

## Tabs

- **Home** — courses, recent saves, news
- **Videos** — For You feed
- **Learn** — learning paths and lessons
- **News** — categorized headlines
- **You** — library, course progress, settings

Share anything to **sync** from another app to add it to the library with background enrichment and summaries.
